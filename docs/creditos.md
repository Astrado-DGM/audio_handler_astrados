# Créditos

## Astrados Audio Handler

Mezclador de música, efectos de sonido y micrófono para Discord.
Desarrollado por **Astrados**.

## Recursos gráficos

- **Imágenes Frutiger Aero**: cielos, orbes de vidrio, burbujas, destello y parlante. Autor: **Asadal** (asadal.com), recopiladas por **Frutiger Aero Archive** (frutigeraeroarchive.org). Uso libre.
  Cambios: recortadas, recoloreadas a azul y morado, combinadas para formar botones, pestañas, casillas y deslizadores, y redimensionadas para cada escala de pantalla.
- **Íconos**: **Heroicons**, de Tailwind Labs, Inc. (heroicons.com). Licencia MIT (texto completo al final).
  Cambios: convertidos a PNG y recoloreados.

## Sonidos

- **Tranquility**, de **Helton Yan** y **Roberto Araujo** (heltonyan.itch.io/tranquility). Licencia Creative Commons Atribución 4.0 Internacional (CC BY 4.0): creativecommons.org/licenses/by/4.0/
  Cambios: de cada muestra se tomó solo la primera nota; se recortó, se le aplicó un fundido de salida, se normalizó el volumen y se convirtió a 44.1 kHz / 16 bits.
  Muestras usadas:
  - Clic: "Aqua Pluck"
  - Activar: "Glassy Gloss"
  - Desactivar: "Underwater Pluck"
  - Confirmar: "Lone Bell"
  - Abrir: "Short Hover"
  - Cerrar: "Glassy Pluck"
  - Error: "Bell Dissonance"
  - Inicio: "Breathy Startup"
  - Aviso: "Tweeting Notification"
